Step 4: Run Ingestion (Import Content to AEM Cloud)
Ingestion is the final step where content from your Migration Set is moved into your AEM as a Cloud Service instance.
How to Start Ingestion

Go to Cloud Acceleration Manager (CAM).
Open your Project.
Select the Migration Set you want to ingest.
Click New Ingestion (or Ingest).

You will see the screen below:

Important: Wipe Existing Content Option
This is the most critical setting on this screen.

Warning:
If you check “Wipe existing content before ingestion”, it will permanently delete everything currently on your Cloud Author/Publish instance. Only use this when you are sure.

Final Steps

Review your selections carefully.
Keep “Use pre-copy to speed up ingestion” checked.
Click the Ingest button.
Monitor the ingestion progress in CAM.
Once complete, log into your AEM Cloud Author instance and verify the content.


Quick Tips for Ingestion

Always do a test ingestion on a small migration set first.
For regular updates (top-ups), do not enable Wipe.
Start with Author service, then repeat for Publish if needed.
After ingestion, check a few pages and assets to confirm everything migrated correctly.
