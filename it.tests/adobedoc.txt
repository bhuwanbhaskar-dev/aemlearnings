After Entering the Extraction Key in Source CTT – Next Steps
Once you paste the Extraction Key from CAM into the Source AEM CTT screen, follow these steps:
1. Fill Migration Set Details

Name: Give your migration set a clear name (e.g., Homepage_Migration_May2026)
Project name: It should auto-link to your CAM project (confirm it’s correct)

2. Set Parameters

Include versions:
Check this box only if you need old versions of pages/assets.
Leave it unchecked for most migrations (saves time and space).


3. Select Paths to Include (Most Important Step)
You have two options:
Option A – Manual Path (Recommended for beginners)

Type the path you want to migrate (example: /content/my-website)
Click the checkmark icon to validate the path
Add more paths if needed

Option B – Upload CSV

Prepare a simple CSV file with one path per line (no commas)
Click Upload CSV and select your file

4. Add Paths to Exclude (Optional but Useful)

Add any folders you don’t want to migrate
Example: Exclude /content/dam/temp or /content/my-site/drafts

5. Create the Migration Set

Click Create / Save (button name may vary slightly)
Your Migration Set is now created and linked to CAM

6. Start Extraction

Click Start Extraction (or Extract)
The tool will begin copying content to temporary cloud storage
You can monitor progress in:
Source AEM CTT screen, or
CAM dashboard


7. After Extraction is Complete

Go back to Cloud Acceleration Manager (CAM)
Open your Project → Migration Set
Click Start Ingestion
Important: Be careful with the “Wipe existing content” option — it deletes everything on the target Cloud instance.
